☁️ Google Apps Script 云端配置

⚠️ 为什么不同设备看不到相同设置？
本系统是单一 HTML 文件，班级和考试设置默认只存在您浏览器的本地缓存，无法自动同步到其他设备。
配置下方的 Google Apps Script 接口后，班级列表、考试时间、学生成绩都将存储在 Google Sheets 云端表格中，任何设备打开都能自动获取最新设置。
📋 点击展开：一次配置，永久多端同步（约10分钟）

第①步：新建 Google Sheets 表格

打开 sheets.new，命名为「HSK考试系统」，不需要填任何内容，系统会自动创建工作表。

第②步：打开 Apps Script

第③步：部署为网络应用

点击右上角「部署」→「新建部署」
 · 类型：网络应用
 · 执行身份：我（您的帐号）
 · 具有访问权限的用户：所有人
→ 点「部署」→ 授权后复制 Web 应用网址

第④步：粘贴网址并保存

将 Web App 网址粘贴到下方输入框，点「💾 保存网址」。
再点「🧪 测试连接」，出现绿色✅提示即配置成功。

第⑤步：重新保存班级和考试时间

测试成功后，重新点一次「保存班级设置」和「保存考试设置」，
将现有配置推送到 Google Sheets 云端。
之后任何设备打开登录页，都会自动从云端读取最新班级和考试时间。
⚠️ 注意：每次修改 Apps Script 代码后，必须重新「新建部署」才能生效，不能用旧网址。
